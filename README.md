# Client Database Management Site  

A full-stack web application for managing train schedules, built with **MySQL** and **Express.js** on the backend and **JavaScript, HTML, and Handlebars** on the frontend. The app supports full **CRUD functionality** (Create, Read, Update, Delete) and provides a responsive interface for interacting with client data.  

## Features  
- **Full-Stack Architecture**: MySQL + Express.js backend, JavaScript/Handlebars frontend  
- **CRUD Operations**: Create, view, update, and delete train schedules  
- **Relational Database**: Normalized schemas ensuring data integrity and efficient queries  
- **RESTful API Endpoints**: Clean, modular, and scalable routes for data management  
- **Dynamic UI**: Server-side templating with Handlebars for interactive content rendering  

## Tech Stack  
- **Frontend:** HTML, CSS, JavaScript, Handlebars  
- **Backend:** Node.js, Express.js  
- **Database:** MySQL  
- **Tools:** Git, Postman  

## Project is currently unhosted as the database was stored on a school server
